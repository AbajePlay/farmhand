# Changelog

## [1.0.0] - 2026-08-25

### Added
- Farmer villagers now replant the crop they just harvested instead of the first
  plantable seed in their inventory.
- Falls back to vanilla behaviour when the farmer is not carrying the matching
  seed, so a plot is never left empty because of this mod.

### Notes
- Server-side only; no client installation required.
- No dependencies, no configuration, no commands.
- Fabric 1.20 - 26.2, NeoForge 1.20.2 - 26.2.
